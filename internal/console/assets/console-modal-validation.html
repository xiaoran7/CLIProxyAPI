Uptime Kuma 监控探针配置
Console 提供了专用的轻量级免密健康接口，可直接配置至 Uptime Kuma 的 HTTP(s) - Keyword / Status 监控项：
https://your-domain.com/api/status/quota
• HTTP 200: 所有 Key 额度安全，网关持久化正常
• HTTP 429: 存在 Key 触及每日硬限额已被拦截（Uptime Kuma 自动告警）
• HTTP 503: 存储持久化 Outbox 队列积压或 Flush 连续失败
• 支持追加参数 ?strict=1，在达到 85% 预警阈值时立即返回 503 触发报警。
