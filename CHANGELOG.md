### Added
- **WorkBuddy / CodeBuddy Dual-Realm Native Suite (`internal/auth/workbuddy/`, `workbuddy_executor.go`, `management.html`)**:
  - **Dual-Realm & Overseas Egress (`workbuddy.go`)**: Native routing for International (`workbuddy`, `workbuddy.ai`) and Mainland China (`workbuddy-cn`, `copilot.tencent.com`); supports `WB_CN_CHAT_UPSTREAM` (`https://www.workbuddy.cn`) to bypass overseas TLS RST drops while preserving `X-Domain: copilot.tencent.com`.
  - **Per-Model Credit Multipliers & Variant Mode (`workbuddy_credits.go`, `openai_handlers.go`, `handlers_multiplier.go`)**: Fetches live rates from `GET /v3/config` with `preserveModelCredits` protection; supports `models.variant-mode` (`compact` default, `raw`, `all`), emitting `:Nx` suffixes (e.g. `workbuddy/claude-opus-5-5:3.33x`) and rejecting mismatched multipliers with HTTP 400 (`model_multiplier_mismatch`, `TestExtractAndValidateModelMultiplier`, `TestApplyWorkBuddyCreditsOverlaysStaticModels`).
  - **Billing Meter Quota & Expiry Tracking (`quota.go`, `plugin_quota.go`)**: Queries `/get-user-resource-summary`, `/get-enterprise-user-usage`, `/get-user-resource-paid-packages`, and `/get-user-resource-free-packages` with fallback to `/v2/billing/meter/checkin-activity-status`, exposing real point balances and earliest package cutoff timestamps (`expires_at`, `runs_out_at`).
  - **CST Daily Check-in Engine & Outage Compensation (`checkin.go`, `workbuddy_checkin.go`)**: UTC+8 daemon with atomic persistence (`workbuddy_checkins.json`), runtime toggle (`PUT /v8/management/workbuddy/checkin`), and official 500-credit compensation claiming (`GET/POST /v8/management/workbuddy/compensation`, `TestCheckinEngine_EnabledToggle`, `TestCheckinEngine_CompensationPersistenceAndDeduplication`).
  - **Interactive OAuth & Singleflight Refresh (`login.go`, `token.go`)**: CLI/Web QR login (`--workbuddy-login`, `/v8/management/oauth/auth-url?provider=workbuddy`), singleflight token refresh (`/v2/plugin/auth/token/refresh`), and `workbuddy-cn-<nickname>` credential naming.
- **OpenCode Zen 1M Free-Tier Protocol (`opencode_cloaking.go`, `opencode_models.go`, `openai_compat_executor.go`)**:
  - **Cloud WAF Alignment & Tool Hardening**: Rewrites `/zen/v1` to `/inference/v1`, sanitizes `oc_sk_...` keys (`sanitizeOpenCodeAPIKey`), injects `opencode/1.19.0` headers with 1000-entry LRU session affinity (`ses_...`), injects valid `bash`/`read` schemas, and strips stub tool calls across streaming (`openCodeStreamFilter`) and non-streaming responses (`TestOpenAICompatExecutorOpenCodePrepareRequestEndpointRewrite`, `TestAggregateOpenCodeSSEToChatCompletion`).
  - **1M Free Model Catalog**: Zero-config static catalog supporting `glm-5.3-flash-free`, `beam-free`, `nemotron-3.5-super-vl-free`, `minimax-m3.1-flash-free`, `deepseek-v4.1-flash-free`, `cat-jam-free`, `big-pickle`, and `step-5-preview-free`, plus OpenRouter baseline catalog (`openrouter_models.go`).
- **Multi-Strategy Quota Load Balancing & Persistent Session Affinity (`sdk/cliproxy/auth/`)**:
  - **Smart & Pace Selectors (`selector_pace_smart.go`)**: Added `smart` (prioritizes earliest resetting quotas across `fine`/`low`/`spent` tiers with hour-truncated cache stability) and `pace` (ranks by hourly burn headroom within a 10% tolerance band, `TestSmartSelector_SoonestResetFirst`, `TestPaceSelector_HighestHourlyPace`).
  - **429 Rate-Limit Sink & Persistent Affinity (`sink.go`, `session_cache_store.go`, `info.go`)**: Demotes HTTP 429 accounts to tail queues; persists session bindings (`session_affinity.json`) across restarts with first-user-turn anchoring and multi-agent session headers (`X-Magpie-Session`, `X-OpenCode-Session`, `X-Continue-Session-Id`, `X-Cursor-Session-Id`).
- **Stream Resilience, Compression & Zero-Knowledge Redaction**:
  - **SSE Keep-Alive & Loop Guard (`conductor_stream.go`, `loop_guard.go`)**: Emits 15s `: keep-alive` comments during slow reasoning to prevent Cloudflare/Nginx 524/504 timeouts; aborts repetitive 256-window thinking loops (`stream_loop_detected`, `TestLoopGuardReasoningLoopTrip`).
  - **Selective Gzip, Body Decompression & Redaction (`selective_gzip.go`, `request_body.go`, `sdk/cliproxy/redact/`)**: Compresses non-streaming responses via pooled `gzip.Writer`; decodes inbound `gzip`/`br`/`deflate`/`zstd` payloads with bomb protection; masks secrets/PII into deterministic HMAC-SHA256 placeholders (`{{API_KEY_...}}`) with streaming restoration (`StreamRestorer`, `TestConductor_ExecuteStream_Redaction_Streaming`).
- **Embedded CPAMC v1.26.2 Console & Governance (`management.html`, `internal/api/handlers/management/`, `tools/rt2cpa/`)**:
  - Added `WorkBuddySuite` drawer, split `WorkBuddy (en)/(cn)` quota tabs, `global-excluded-models` wildcard filtering (`/v8/management/models/exit-catalog`), `主 Key (Master)` badge, standalone RT2CPA web converter (`tools/rt2cpa/app.py`), and dual-layer LLM documentation (`llms.txt`, `llms-full.txt`) reducing doc context by 76%+.

### Fixed
- **WorkBuddy Protocol & WAF Compliance (`workbuddy_executor.go`, `workbuddy_cloaking.go`, `workbuddy_models.go`)**:
  - **Upstream `stream: true` Enforcement (`11101` Fix)**: Non-streaming `"stream": false` requests caused upstream `11101` (`Get empty response from llm`) rejections because Tencent backend requires SSE framing. Enforced `"stream": true` before and after user payload rules and folded SSE chunks via `AggregateWorkBuddyStream` (`TestAggregateWorkBuddyStream_Basic`, `TestAggregateWorkBuddyStream_ReasoningAndToolCalls`).
  - **Desktop 5.8.4 Channel Validation (`11128` Fix)**: Missing 5.8.4 trace headers or missing initial system role triggered WAF `11128` channel errors. Injected full conversation header family (`X-Conversation-ID`, `X-Conversation-Request-ID`, `X-Root-Request-ID`, `X-Conversation-Message-ID`, W3C/B3 traces), stripped legacy `X-Machine-ID`/`X-Session-ID`, and prepended system prompts via `EnsureWorkBuddySystemPrompt` (`TestEnsureWorkBuddySystemPrompt`).
  - **CN Realm Free-Tier Isolation**: Removed non-existent `-free` aliases from `staticWorkBuddyCNModels` and blocked `-free` fallback lookups in CN realm.
- **Provider Routing & Multiplier Isolation (`provider.go`, `handlers_execution.go`, `openai_handlers.go`)**:
  - **Cold-Start Static Fallback & Multiplier Isolation**: Dynamic model queries before credential warmup returned `unknown provider`, while global credit maps leaked `:1x` suffixes onto non-WorkBuddy models. Added `LookupStaticModelProviders`, restricted credit fallback strictly to WorkBuddy models, and preserved canonical upstream model names when routing aliases without suffixes.
- **Auth File Isolation & CPAMC Stability (`auth_files.go`, `filestore.go`, `support_nocgo.go`, `management.html`)**:
  - Excluded internal state files (`session_affinity.json`, `*checkins.json`) from credential listings/uploads/deletions (`TestDeleteAuthFile_RejectsInternalStorageFiles`); enabled `X-CPA-SUPPORT-PLUGIN: 1` in `CGO_ENABLED=0` builds; bumped Antigravity Hub UA to `antigravity/hub/2.23.0 darwin/arm64`; fixed `Fp` sequence parser bug and `/v0/management` log fallbacks in `Wy`.
